# 🐕 AI 狗狗后院 v3.0（模块化 + 模组版）

> 一只由 AI 驱动、会自己思考的小狗后院模拟器。单文件 HTML，浏览器打开即玩，完全离线可用。
> v3.0 在 v2.0 基础上整合《通用游戏 AI 逻辑模板》，重构为 **状态 + 动作 + 策略 + 评估** 的通用架构，并加入 **模组系统（Mods）**，支持注册新动作、新策略、新物件与渲染钩子。

## 🎮 快速开始

直接双击打开 `dog_backyard.html`（推荐 Chrome / Edge 浏览器）。

- **点击画布** → 狗狗走过去
- **点大树 / 水潭 / 消防栓 / 狗粮碗 / 垃圾桶** → 狗狗互动
- **空格** = 暂停/继续；**F** = 扔飞盘、**B** = 扔球、**P** = 装狗粮
- 顶部工具栏：扔球/飞盘/骨头、装狗粮、奖励零食、摸摸、训练指令、音效/暂停/倍速

## 🧠 AI 大脑（通用 AI 模板落地）

架构对应《通用游戏 AI 逻辑模板》的核心理念：

```
感知(Sense) → 决策(Think) → 行动(Act) → 环境更新 → 循环
```

| 模板概念 | 本游戏实现 |
|---|---|
| **State 状态** | 全局 `S` 对象：精力/饥饿/膀胱/心情/忠诚/时间/天气/位置… |
| **Action 动作** | `Dog.Actions` 注册表：move_to/pee/bark/sleep/dig/eat/… |
| **Policy 策略** | `Dog.Strategies` 注册表，六种策略可插拔切换 |
| **Evaluate 评估** | `Dog.Evaluate.state()` / `Dog.Evaluate.action()` 打分函数 |

### 六种策略

| 策略 | 说明 | 适合 |
|---|---|---|
| **规则 Rule**（默认） | if-else 专家规则，可控可解释 | 零配置日常玩 |
| **随机 Random** | 合法动作随机选 | 测试/娱乐 |
| **贪心 Greedy** | 用评估函数给每个动作打分，选最高分 | 快速聪明 |
| **蒙特卡洛 MCTS** | 多轮随机模拟取平均分，更稳健 | 追求"思考"感 |
| **Q-Learning** | 维护 (状态→动作) 价值表 Q，越玩越聪明，Q 表自动存档；可点「🧠 Q学习一轮」手动强化 | 见证 AI 成长 |
| **远程 AI** | OpenAI 兼容 API + function calling，大模型控制狗狗（支持 OpenAI / DeepSeek / Kimi / Ollama） | 最强"人格" |

> 在「AI 大脑」面板顶部下拉切换策略。远程 API 直调可能有 CORS 限制，连不上可改用本地 Ollama 或本地策略。

## 🧩 模组系统（Mods）

模组让任何人都能给游戏"加东西"而不用改主文件。

### 快速体验

1. 点击「✨ 载入示例模组(猫)」→ 院子里会随机出现一只猫，狗狗可以和它互动，新增"撸猫/吓猫"动作与"猫咪之友"成就。
2. 点击「📂 加载模组(.js)」选择本地模组文件，或填写 URL 加载远程模组。

### 模组 API

每个模组是一个对象，通过全局 `Dog.Mods.register(mod)` 注册：

```js
Dog.Mods.register({
  id: 'my-mod',                    // 必填，唯一 ID
  name: '我的模组',                // 显示名
  version: '1.0.0',
  desc: '一句话说明',

  // 生命周期钩子（可选）
  onLoad(D){ ... },                // 注册时：可注册动作/策略/物件
  onUnload(D){ ... },              // 卸载时清理
  onTick(dt){ ... },               // 每帧逻辑（dt 为秒）
  onRender(ctx){ ... },            // 每帧渲染叠加（ctx 为画布上下文）
  onAction(name, args, result){},  // 任意动作执行后回调
  onSave(data){},                  // 存档时往 data 里写自己的字段
  onLoad(data){},                  // 读档时读回自己的字段
});
```

### 注册新动作

```js
Dog.Actions.register('my_action', {
  desc: '动作描述（供远程AI提示）',
  params: { type:'object', properties:{ reason:{type:'string'} } },  // 可选，供远程AI
  value(dog, S){ return 10; },      // 可选：供 Greedy/MCTS 评估打分
  run(args, Dog){ /* 执行逻辑，返回描述字符串 */ return '做了某事'; }
});
```

注册后新动作会自动出现在 Greedy/MCTS/Q-Learning/远程AI 的候选列表中。

### 注册新策略

```js
Dog.Strategies.register('my_strategy', {
  label: '我的策略',
  tick(){ /* 选择并执行一个动作，例如 execTool('move_to',{...}) */ }
});
```
然后在「AI 大脑」面板下拉即可选择（策略 ID 会自动列出）。

## 📂 数据与备份

所有进度、记忆、外观、AI 配置、Q 表都自动保存在浏览器本地（localStorage）。换设备或存档用「📦 导出备份」生成 JSON 文件，需要时「📥 导入」恢复。
